# DevOps Learning Journey 🚀

Цей репозиторій містить мої практичні роботи під час підготовки до ролі DevOps Engineer.

## Скрипти в цьому репозиторії:
*   **SystemAudit.ps1**: Збирає дані про версію ОС та розраховує час роботи системи (Uptime).
*   **Get-SystemHealth.ps1**: Моніторить ресурси в реальному часі (CPU, RAM, Disk).

## Як запустити:
1. Відкрийте PowerShell від імені адміністратора.
2. Виконайте: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`.
3. Запустіть скрипт: `.\Get-SystemHealth.ps1`.
